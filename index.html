2Tower placement diagram (schematic) — full-bleed 16:9

Your diagram will render here, filling the full width edge-to-edge, after you click Generate.

Stations that sit on a junction — where the route splits into two lines and rejoins later — are automatically detected and drawn as a labelled branch lane, connected back to the main line with dashed bridge connectors, instead of being silently dropped.

Using Canva? Click Download PNG above, then in Canva choose Create a design → Upload → your PNG — it drops in at full resolution as a background you can layer text/branding over. The generated .pptx file can also be imported directly via Canva's File → Import file option if you're editing the deck itself.
